# Build times and per-feature compile cost at the M1 integration (2026-10-24)

Written by `m2-integrate-m1` (worker `cbdcd8ef`) for F-029 (`ai/RULES.md` rule 23, D-025). Every figure is pasted from
the tool that produced it (rule 7). The previous figures are in `2026-10-23-build-times.md` (M0 tree, base commit
`6e22a6f`); the times changed, so this file exists. The matching readiness criteria are in `2026-10-24-m1.json`.

## Method

- Machine: 10 cores, `CARGO_TARGET_DIR=/Users/dct/.cargo/shared_rust_target`, toolchain 1.99.1 (`rust-toolchain.toml`,
  unchanged). Tree: the main checkout, branch `mission/observatory-v1`, merge commit `c2fb42a`
  (`Integrate m1: board, replay, attach, usage-log source`), documentation edits in the working tree (no Rust file changed).
- Order: `make check` once, then `cargo llvm-cov` alone after `ps -axo pid=,command= | grep -E 'cargo|trunk'` showed
  no build process, then, later, the three inner-loop commands below. A cold `make check` was not measured: the toolchain
  and the dependency set did not change in a way that this file isolates (new crates were added in M1; their
  first build is part of the workers' handoff times).
- "Warm" = the shared target directory already held the build of this tree's dependencies.
