## Method

- Machine: 10 cores, `CARGO_TARGET_DIR=/Users/dct/.cargo/shared_rust_target`, toolchain 1.99.1 (`rust-toolchain.toml`,
  unchanged). Tree: the main checkout, branch `mission/observatory-v1`, merge commit `7385b62`
  (`Integrate m2: rpc source, hosted launch, scrutiny feature_defined`), documentation edits in the working tree (no Rust
  file changed after the merge).
- Order: `make check` once, then `cargo llvm-cov` alone, then, in the same slot, the three inner-loop commands below
  (skill step 2). A cold `make check` was not measured: the toolchain did not change.
- "Warm" = the shared target directory already held the build of this tree's dependencies.
