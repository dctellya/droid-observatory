# m5-time-states-and-rework-core

## SPEC §9

- Row (F-NEW): **core::metrics exists: time states, rework windows, waste enums, throttled** (feature `m5-time-states-and-rework-core`, batch 1; rule 24 decisions inside the slice, none changes scope, caps or models). Module `crates/observatory-core/src/metrics/` (`state`, `rework`, `waste`, `throttled`, `notes`, `span`), pure over mapped events, compiles with `--no-default-features` on wasm32.
- Row (F-NEW): **a measured span ends at the event's `at`, not starts there.** Architecture §9 says "each event with `duration` contributes `[at, at + duration]`"; the mapper stamps the END of what it measured (`tool_result.at`, the turn outcome line, the subagent's last line, `mapping/v1/mod.rs` 552, 587, 386) and sets `duration` to the time since its start. The engine reads `[at - duration, at]`. With the architecture's direction the overnight escalation (turn of 15327852 ms stamped 2026-10-22T18:01:03Z) would have run 4 h into the stop. The architecture sentence is amended at the next boundary.
- Row (F-NEW): **rework `cause` is the lane id of the lane that holds the opening event** (`scrutiny`, `user_testing`, `integrate`, `gate` in the default template; `rework_causes(&template)` lists them). The contract (VAL-METRIC-005 "`integrate` → `integration`", the validator-notes list "`scrutiny`, `user_testing`, `integration`, `gate`") and architecture §9 ("Causes: ... `integration`") name the legacy word `integration`; the m3 note (cycle-template refactor) and F-041 forbid it, so the code and the closed-set test use `integrate`. The contract text, architecture §9 and the reference CSV (when the owner produces it) change together to `integrate`.
- Row (F-NEW): **pairing keys come from `Notes`, not from the events.** `Event` has no payload: the scenario of a `qa.scenario.*` and the check of a `check.*` are not on the mapped event (the forge's event ids name the run, not the check). `metrics::Notes` carries the key per event id (`with_key`), the reason per pause marker (`with_pause_reason`) and the question an app answer closes (`with_answer`, `human_actions.payload_ptr`). An event with no key pairs by kind (the oldest open window), and a pass for another scenario or check does not close a window only when both sides are keyed. A red of a check that already has an open window opens no second one (the store's rule in `apply_window`).
- Row (F-NEW): **time-state rules fixed where the architecture left a choice** (the oracle validates them, B-008): Active and RetryFailure come from `event_span`; Retry > Active > WaitingHuman > WaitingValidation > Idle where claims overlap (an open question under an active span is Active, as architecture §9 says); a question waits from `question.asked` to the next `question.answered` or `intent.answered`, a permission from `permission.requested` or `approval.requested` to the grant or denial; a green check waits for the merge (`WaitingHuman(Merge)`) from the first `check.passed` to `handed_to_cd` or the next `check.failed`; `task.done` and `rework.resolved` wait for validation until an event of a validator role; a gap is `IdleQueued` when another feature's active span covers it, else `IdleUnscheduled`. `waste_rework_s` is the Active time inside a merged rework span (no seventh waste state exists for it).
- Row (F-NEW): **`throttled` leaves the partition empty, Active included.** Markers: `mission.paused` with the next `mission.resumed` (reason from `Notes`, else `unknown`), and, with no resume, every `escalation.raised` or unpaired `mission.paused` in a run: from the last event before the run to the first event after it (to `end` when none follows). Minutes are rounded to the nearest. On the M0 golden events the engine measures ONE interval, 2026-10-22T18:01:02.011Z to 2026-10-23T06:34:54.182Z, `minutes` 754 (`mission_minutes` 754), reason `unknown`; the owner's figure was about 755 and is not written anywhere. The stop is also carved out of Active, because a subagent's whole-run span would otherwise carry 45233 s of the stop (`user-testing-validator-s` active 46934 s before the carve, 1701 s after).
