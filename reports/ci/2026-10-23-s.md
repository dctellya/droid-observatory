## Failure

Failing step: `rust` / `clippy`, which runs `make lint` (`cargo clippy --workspace ... -D warnings`).
Log excerpt (run 39920664605):

```text
The system library `glib-2.0` required by crate `glib-sys` was not found.
The system library `gobject-2.0` required by crate `gobject-sys` was not found.
Package glib-2.0 was not found in the pkg-config search path.
make: *** [Makefile:83: lint] Error 101
```

Cause: the workspace now contains `apps/observatory-app/src-tauri` (Tauri 2), whose Linux build
needs the GTK and WebKit system libraries. The `ubuntu-latest` runner does not have them, and
`rust` runs `make lint` and `make test` over the whole workspace. D-011 limits `cargo deny` to the
macOS and wasm32 targets, so `deny` is green; the `rust` job was never run on the S worktree
because `mission-branch.yml` does not run on `wt/**`. `make check` on macOS is green (exit 0) at
`38e5617` and `2ba8fb0`.

Options for the fix feature (not applied by the integration feature): install the Tauri Linux
libraries in the `rust` job (`libwebkit2gtk-4.1-dev` and dependencies; adds apt time against the
3-minute budget), or run `lint` and `test` for `observatory-core` and `observatory-cli` on Linux
and leave the Tauri shell to the macOS bundle job. `gate.yml` runs the same job and has the same
problem on the final pull request.
